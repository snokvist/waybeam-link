# waybeam-link Roadmap — moved

The roadmap for this repo now lives in the coordination repo, at
**`waybeam-coordination/roadmaps/waybeam-link.md`**.

waybeam-link was registered as a `waybeam-coordination` submodule on 2026-07-30
(coord PR #126). That repo's convention is that all roadmaps live centrally in
`roadmaps/`, one file per repo, as the single source of truth — sub-repos do not
keep their own. Its `/roadmap` command scans for duplicates and flags them, so
the items previously listed here were folded into the central file rather than
maintained in two places.

This stub remains only so existing references keep resolving (see
`docs/preflight-open-issues.md`). Do not add roadmap items here.

**Spec-bearing work is unaffected**: `PROTOCOL.md` plus a numbered
`docs/review-log.md` Pass entry remain the process for anything spec-adjacent,
and both stay in this repo. The roadmap only ever tracked *intent*.
