State guide

HOLD: adaptive selection is healthy and keeping the current profile because no promotion or demotion rule fired.

PINNED: adaptation is intentionally disabled because the configured minimum and maximum profile are the same. This is expected in the Ethernet bench.

PROMOTE / DEMOTE: moving up/down the profile ladder. FREEZE: flap protection is temporarily blocking promotion. FAILSAFE: return reports are stale or absent; promotion is forbidden and the selector may step down.
